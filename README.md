# ⚡ ZeikNem — Zeik Estudos

App de estudos para o ENEM: avaliador de redação (padrão ENEM, por foto ou texto), 109 questões comentadas em 15 matérias, simulado cronometrado com gabarito, matemática do zero, leitor de texto com voz e gamificação estilo Duolingo.

## 🌐 Publicar este repositório (GitHub Pages)

1. Este repositório já está no formato certo: `index.html` na raiz junto de `manifest.webmanifest` e dos ícones
2. Vá em **Settings → Pages**
3. Em *Build and deployment*: **Source = Deploy from a branch** → Branch **main** → pasta **/(root)** → **Save**
4. Aguarde 1–2 minutos → o site fica em:
   `https://SEU-USUARIO.github.io/zeiknem/`

## ▲ Rodar na Vercel depois (opcional)

1. Acesse **vercel.com** → entre com a conta **GitHub**
2. **Add New → Project → Import** neste repositório
3. Não precisa configurar NADA (site estático) → **Deploy**
4. Pronto: link `zeiknem.vercel.app` + HTTPS + atualiza sozinho a cada commit

## 📁 Arquivos (sempre juntos)

| Arquivo | Para que serve |

| `index.html` | O app completo |

## ✏️ Atualizar o site no ar

Edite (ou suba por cima) o `index.html` aqui no GitHub → o site atualiza sozinho em ~1 minuto (GitHub Pages) ou em segundos (Vercel).
